# Task 4 - Sales Performance Dashboard

## Objective
Designed an interactive sales dashboard using Power BI to monitor sales performance and provide business insights.

## Project Overview
- Imported the Sales-Export_2019-2020 dataset into Power BI.
- Cleaned and transformed the data using Power Query.
- Created DAX measures for Total Sales, Total Cost, Total Profit, Total Orders, and Profit Margin.
- Built KPI cards to display key business metrics.
- Added interactive slicers for Country, Category, and Device Type.
- Created visualizations to analyze:
  - Monthly Sales Trend
  - Sales by Country
  - Sales by Category
  - Sales by Device Type
  - Sales by Sales Manager
  - Sales by Sales Representative
  - Top 10 Customers
- Designed a two-page interactive dashboard with a consistent layout and color theme to support business decision-making.

## Tools Used
- Power BI
- Power Query
- DAX
